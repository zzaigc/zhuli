## 模块职责边界

| 模块 | 负责 | **不负责** |
|---|---|---|
| `core.orchestrator` | 主循环编排、状态机、人在回路、错误恢复 | 具体能力实现、提示词内容 |
| `core.planner` | 目标拆解、重规划（产出含完成标准） | 执行动作 |
| `core.reflection` | 反思判定（continue/replan/done/escalate） | 动作选择 |
| `agents.*` | 各智能体的提示词、Schema、协作方式 | 页面/命令的具体操作 |
| `llm.*` | 与模型 API 通信、能力路由 | 业务逻辑 |
| `browser.*` | Playwright 操作与观察 | 决策 |
| `computer.*` | 命令执行与护栏 | 决策 |
| `video.*` | ffmpeg 方案与执行 | 决策 |
| `integrations.*` | 与目标工具的交互适配（复用 browser/computer） | 直接操作 Playwright/进程 |
| `memory.*` | 技能存储与检索 | LLM 调用（由 agents 注入） |
| `security.*` | 加密原语、密钥、安全容器 | 业务语义 |
| `credential.*` | 凭据持久化与卡片事件 | 加解密实现（委托 security） |
| `console.*` | 路由、WS 广播、静态托管 | 业务逻辑 |

## 依赖方向（防止循环引用）

```
console ──► core.orchestrator ──► agents ──► llm ──► config
   │              │                  │
   │              ├──► browser/computer/video/integrations
   │              ├──► memory ──► llm
   │              └──► security ──► config（仅延迟导入）
   └──► credential ──► security
```

要点：`security` 与 `credential` 对 `config` 的引用均为**函数内延迟导入**，
避免模块加载期因配置缺失而崩溃（`get_settings()` 在缺配置时会抛 `FileNotFoundError`）。

## 运行时产物（均在项目内）

`.zhuli_runtime/` = `{browsers, profile, venv, memory.db, *.log}`

浏览器路径由 `main.py` 在**导入 playwright 之前**设置 `PLAYWRIGHT_BROWSERS_PATH` 生效；
profile 由 `browser/driver.py` 把相对路径解析到项目根。
