# 06 · 技能挖掘智能体（skill_miner）

**源码**：`src/zhuli/llm/prompts.py` → `SYSTEM_SKILL` / `SKILL_SCHEMA`
**职责**：把成功任务提炼为可复用技能，并在再次使用时**合并新经验自动迭代**。

## 提示词（提炼）

```
你负责把一个成功完成的任务提炼成「可复用技能」。
技能应当足够通用、可迁移到相似目标，而不是只描述这一次。
只输出结构化字段，不要解释。
```

调用时输入：`本次任务目标` + `执行过程`。

## 输出 Schema

```json
{
  "type": "object",
  "properties": {
    "name":        { "type": "string" },
    "description": { "type": "string" },
    "trigger":     { "type": "string" },
    "procedure":   { "type": "string" },
    "tags":        { "type": "array", "items": { "type": "string" } }
  },
  "required": ["name", "procedure"]
}
```

## 提示词（合并迭代）

当已有相似技能时，把本次新经验合并进去（**自动迭代**）：

```
你负责把「已有技能步骤」与「本次新经验」合并成更通用、更精简的可复用步骤。
只输出合并后的步骤文本，分条列出，不要解释。
```

输入：技能名 + 触发条件 + 已有步骤 + 本次新经验。

## 自进化闭环

```
成功任务（且过程长度 >= 30 字符）
   │
   ├─ 检索相似技能（语义 embedding / 关键词回退）
   │
   ├─ 有相似 → 合并精炼 → 🔄 迭代更新技能（并刷新 embedding）
   └─ 无相似 → 提炼新技能 → 🧠 学到新技能
                                  │
                    成功复用次数 >= skill_promote_threshold
                                  │
                        ⬆ 升格为 skill:* 专项智能体
```

## 检索方式

| 方式 | 条件 | 说明 |
|---|---|---|
| 语义检索 | 配置了 `routing.embeddings` | 用向量余弦相似度，跨表述也能命中 |
| 关键词回退 | 未配置或失败 | 拉丁词 + 中文二元组混合分词 |

## 关键约束

- **只从成功任务学习**（`status == done`），避免把失败路径固化成技能；
- 过程过短（< 30 字符）不学习，避免沉淀无意义技能；
- 学习/检索失败**静默兜底**，绝不影响主流程。

## 技能升格

`AgentRegistry.promote_skill()` 在技能 `success_count >= threshold` 时，
把它注册为 `skill:*` 专项智能体 —— 该经验此后会作为**团队中的新模块**持续提供经验上下文。
这是「用得越多，模块越多、越智能」的实现点。
