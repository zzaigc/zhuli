# 05 · 事件契约（前后端唯一耦合点）

> **铁律**：新增事件类型必须**同时**更新 `core/events.py` 的 `Event` 联合类型与前端的分发逻辑。
> 否则后端会推送前端不认识的事件，或前端渲染 undefined。

源码：`src/zhuli/core/events.py`。序列化：`to_ws()` → `json.dumps(model_dump(mode="json"), ensure_ascii=False)`。

## 事件总表（13 类）

| type | 用途 | 关键字段 |
|---|---|---|
| `plan` | 子任务清单与进度 | subtasks, current, done, verification |
| `reflection` | 反思结论 | status, reason |
| `step_log` | 每步动作与观察摘要 | step, action, observation_summary |
| `screenshot` | 截图与高亮 | image_b64, highlights |
| `command` | 命令/终端输出 | cmd, stream, line, exit_code |
| `confirm_request` | 危险操作确认 | reason, pending_action |
| `credential_request` | 安全凭据卡片 | fields |
| `chat` | 对话消息 | role, text |
| `status` | 任务状态 | state, message |
| `skill` | 技能沉淀/复用/升格 | name, description, action, reason |
| `think` | **思维链** | stage, text |
| `agent` | **智能体活动** | agent, stage, summary, verdict |
| `error` | 错误提示 | message |

## 关键字段枚举

```python
# Action（动作，也是能力模块执行的统一输入）
action: click | type | goto | scroll | submit | wait | navigate
        | shell | video | tool_task | fill_credential | done
target: str | None      # 元素 id / URL / 命令 / 工具名 / 字段名
value:  str | None      # 输入文本（脱敏后才可入日志）
reason: str | None
thought: str | None     # 一步思考（思维链可见化的来源）

# think.stage
plan | decide | reflect

# agent.stage
plan | observe | decide | critique | risk | reflect | skill | delegate | consensus

# agent.verdict
accept | revise | abort | safe | confirm | danger | continue | replan | done | escalate

# skill.action
learned | updated | matched | promoted

# status.state
idle | running | paused | awaiting_confirm | awaiting_credential | stopped | error

# reflection.status
continue | replan | done | escalate
```

## 前端分发模板（静态控制台）

```javascript
ws.onmessage = (e) => {
  const ev = JSON.parse(e.data);
  switch (ev.type) {
    case "chat": ...              // 对话
    case "plan": renderPlan(ev);  // 含 verification 渲染
    case "reflection": ...
    case "step_log": ...
    case "screenshot": ...
    case "command": ...
    case "confirm_request": ...
    case "credential_request": ...
    case "status": ...
    case "skill": addSkill(ev);        // 含 promoted（升格）
    case "think": addThink(ev);        // 思维链
    case "agent": addAgent(ev);        // 智能体活动 + 共识
    case "error": ...
  }
};
```

## 前端 → 后端（控制指令）

经同一条 WebSocket 发送：

```javascript
send({ type: "task", goal: "...", target_tool: "codebuddy" });  // 提交任务
send({ type: "confirm", approved: true });                      // 确认/取消
send({ type: "credential", values: { password: "..." } });      // 填卡回传
send({ type: "control", action: "pause" | "resume" | "stop" });
```

## 历史事件缓冲

`console/server.py` 的 `Hub` 会缓存最近 100 条事件，
新连接的客户端会先收到回放 —— 保证**启动期错误**（如浏览器未安装）也能被前端看到。

## 安全约束

- 所有含敏感值的字段（如 `Action.value`）入日志前必须经 `credential.card.redact()` 脱敏为 `***`；
- `credential_request.fields` **只含字段名，绝不含值**；
- 事件不得携带 API Key、主密钥等任何秘密。
