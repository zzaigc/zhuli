# 06 · 配置参考

配置文件：`config/settings.yaml`（不存在时服务会提示复制 `settings.yaml.example`）。
模型定义：`src/zhuli/config/schemas.py`。

## providers（模型供应商）

```yaml
providers:
  - name: deepseek
    base_url: https://api.deepseek.com
    api_key_env: DEEPSEEK_API_KEY        # 环境变量名（推荐）
    # api_key_service: "zhuli:deepseek" # 或 keyring 服务标识
    default_model: deepseek-chat
    embedding_model: text-embedding-3-small   # 可选：技能语义检索用
    models:
      vision: deepseek-chat
      reasoning: deepseek-chat
      default: deepseek-chat
```

- 任意兼容 OpenAI 格式的 API 均可（DeepSeek / Kimi / GLM / OpenAI / 本地 Ollama 等）；
- **敏感 Key 只写引用**（环境变量名或 keyring 标识），绝不写明文。

## routing（能力路由）

```yaml
routing:
  vision: openai          # 含截图/视觉理解的任务
  reasoning: deepseek     # 结构化推理/默认决策
  default: deepseek
  embeddings: openai      # 可选：技能语义检索（留空则回退关键词）
```

## agents（智能体 → 模型绑定）

```yaml
agents:
  planner:     { provider: deepseek, capability: reasoning }
  observer:    { provider: deepseek, capability: default }
  actor:       { provider: deepseek, capability: reasoning }
  critic:      { provider: deepseek, capability: reasoning }
  risk:        { provider: deepseek, capability: default }
  skill_miner: { provider: deepseek, capability: reasoning }
```

- 不给某角色配置或 `provider` 留空 → 沿用 `routing` 中对应 capability 的设置；
- 想「OpenAI 做决策、DeepSeek 做批评」只需分别填不同 provider。

## policy（行为策略）

| 字段 | 默认 | 说明 |
|---|---|---|
| `max_steps` | 40 | 单任务最大步数 |
| `step_timeout_sec` | 120 | 单步超时 |
| `confirm_dangerous` | true | 危险操作/命令弹确认 |
| `auto_execute_safe` | true | 安全动作自动执行 |
| `multi_agent` | true | 多智能体总开关（false = 单脑模式） |
| `self_critique` | true | 执行前自我批评 |
| `observer_enabled` | true | 观察蒸馏 |
| `skill_promote_threshold` | 2 | 技能升格为专项智能体的成功次数阈值 |
| `hive_mode` | false | 蜂巢共识（更准，token 消耗更高） |
| `hive_size` | 3 | 手动蜂群规模（>= 1，无上限）；自动模式 2~8 |
| `bidirectional_mode` | off | 双向开关默认值（三选一，默认关闭）：off = 仅本助理；ide_to_zhuli = IDE 经 MCP 操作 Zhuli；zhuli_to_ide = Zhuli 派发到 IDE；控制台开关是运行时覆盖，重启恢复为本值 |

## security（军事级加密）

```yaml
security:
  master_key_env: ZHULI_MASTER_KEY   # 主口令环境变量名
  pbkdf2_iterations: 600000          # PBKDF2-HMAC-SHA256 迭代次数
  encrypt_credentials: true          # 凭据落库前是否信封加密
```

主口令来源优先级：**环境变量 `ZHULI_MASTER_KEY` > 系统凭据库 > 仅内存会话密钥**。
推荐设置环境变量（口令不落 OS 凭据库，安全性最高）。

## browser

```yaml
browser:
  headless: false
  user_data_dir: .zhuli_runtime/profile   # 相对路径 → 解析到项目内
  viewport: { width: 1280, height: 800 }
```

## computer / integrations

```yaml
computer:
  max_output_chars: 20000
  timeout_sec: 60
  allowed_dirs: []

integrations:
  codebuddy: { type: browser,  url: "https://..." }
  trae:      { type: browser,  url: "https://..." }
  opencode:  { type: computer, command: ["opencode"] }
```

## 环境变量

| 变量 | 作用 |
|---|---|
| `PLAYWRIGHT_BROWSERS_PATH` | Chromium 二进制位置（脚本已自动设为项目内） |
| `PYTHONPATH` | 需指向 `src`（脚本已自动设置） |
| `ZHULI_MASTER_KEY` | 加密主口令（强烈建议设置） |
| `*_API_KEY` | 各 provider 的 Key（按 `api_key_env` 命名） |

## 配置缺失时的行为

服务**不会崩溃**：`orchestrator.start()` 会捕获配置加载失败并推送 `error` 事件到控制台，
页面照常打开并提示复制示例配置。
