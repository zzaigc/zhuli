## 已知限制

1. **Chromium 未在本沙箱下载成功**：`cdn.playwright.dev` 被网络限制（进度卡 0%）。
   在正常联网机器上 `playwright install chromium` 会顺利下到 `.zhuli_runtime/browsers`。
   → 影响：浏览器类任务无法端到端验证；不影响服务启动与其它模块（已优雅降级）。
2. **无 API Key 时 LLM 调用会 401**：需按 `api_key_env` 配置对应环境变量。
3. **蜂巢模式 token 消耗较高**：约为流水线模式的 3 倍，故默认关闭。
4. **缺 `cryptography` 时加密降级**：会回退到仅 keyring 保护并告警（**不会**伪加密）。
5. **React 前端尚未构建**：当前控制台是 `src/zhuli/console/static/index.html`。
