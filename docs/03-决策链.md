# 03 · 决策链（完整顶级思维逻辑）

这是系统的灵魂。单步循环如下，**每一步都可在控制台观测**。

## 单步流程

```
 0) 记录快照 URL（用于失败回滚）
 1) 观察     原始观察 = URL + 目标工具 + 当前子任务 + 完成标准 + 进度 + 可交互元素 + a11y 树
 2) 蒸馏     Observer 智能体 → 只留相关元素、指出障碍（可关闭）
 3) 决策     多智能体流水线 或 蜂巢共识（详见 04）
             → 得到 proposal + criticism + risk + （蜂巢时还有 votes）
 4) 风险确认 risk ∈ {confirm, danger} → 弹人在回路确认（并避免与规则护栏重复弹窗）
 5) 执行     路由到 browser/computer/video/tool:*，经规则护栏与凭据卡片
 6) 记录     脱敏后写日志 + 截图 + 高亮
 7) 反思     Critic 对照「完成标准」判定当前子任务是否达成
             → 推进下一子任务 / 继续 / 重规划 / 完成 / 升级
```

## 关键机制

### 带验证标准的规划
Planner 输出的不只是子任务列表，还包含：
- `verification`：每个子任务的**完成判定标准**（如「搜索框出现关键词且结果列表非空」）；
- `tools`：每个子任务主要使用的能力/工具。

反思阶段据此判定「是否真的完成」，而非凭感觉，这是**闭环可验证**的关键。

### 子任务进度推进
反思判定 `current_done=true` 时，`TaskContext.advance_subtask()` 会把当前子任务标记完成并推进到下一个，
同时推送 `plan` 事件，控制台实时勾选进度。

### 确定性循环 / 卡死检测
纯逻辑判断（不依赖 LLM，因而稳定可靠）：

```python
# 最近 N 个动作的指纹完全相同 => 判定死循环
fps = [f"{a['action']}:{a['target']}" for a in recent]
loop = len(set(fps)) == 1
```

触发后强制重规划：**保留已完成的子任务，只替换无效部分**。

### 错误恢复链路（由轻到重）

| 层级 | 触发条件 | 动作 |
|---|---|---|
| 单步重试 | 执行抛异常 | 先快照回滚（回到上一步 URL），再重试一次 |
| 循环检测 | 连续 3 步动作指纹相同 | 强制重规划（换策略） |
| 批评否决 | Critic 判 `abort` / Risk 判 `danger` | 重规划 |
| 重规划上限 | 重规划累计 > 3 次 | 升级求助（error 状态 + 提示用户介入） |
| 连续失败 | 重试仍失败 | 停止并提示介入 |

### 快照回滚
每步开始时记录当前 URL；单步失败后 `page.goto(上一 URL)`（最佳努力，失败也不影响主流程），
避免因失败动作把页面带到未知状态。

### 可降级
`policy.multi_agent=false` 时，协调器会直接回退到 `core/planner.py` 与 `core/reflection.py`
的单体实现（行为等同传统单决策大脑），保证在模型能力弱或成本敏感时仍可用。

## 反思的四种结论

| 结论 | 含义 | 系统行为 |
|---|---|---|
| `continue` | 当前子任务未达成 | 继续下一步 |
| `done` | **全部**子任务达成 | 结束并沉淀技能 |
| `replan` | 偏离/卡死/循环 | 触发重规划 |
| `escalate` | 信息不足/超出能力 | 升级求助 |

注意区分：`current_done` 表示「当前子任务完成（后面还有）」，`done` 表示「全部完成」。

## 可观测性（全部推送到控制台）

| 内容 | 事件 |
|---|---|
| 规划结论 / 重规划 | `plan` |
| 思维链（规划/决策/反思） | `think` |
| 智能体活动与投票共识 | `agent` |
| 每步动作与观察摘要 | `step_log` |
| 截图与高亮 | `screenshot` |
| 命令/终端输出 | `command` |
| 技能沉淀/复用/升格 | `skill` |

## 时序示例

```
用户: "登录某站并搜索关键词"
 ├─ skill(matched)     复用历史技能
 ├─ think(plan)        规划思路
 ├─ plan               子任务[登录,搜索] + 完成标准
 ├─ [循环]
 │   ├─ agent(observe)   observer 蒸馏
 │   ├─ agent(decide)    actor 提议
 │   ├─ agent(critique)  critic 审查 → accept
 │   ├─ agent(risk)      risk 评级 → confirm
 │   ├─ think(decide)    思维链
 │   ├─ confirm_request → 用户确认
 │   ├─ step_log        #1 click 12
 │   ├─ screenshot      截图 + 高亮
 │   └─ agent(reflect)  → current_done → 推进下一子任务
 └─ skill(learned)     沉淀新技能 / skill(promoted) 升格
```
